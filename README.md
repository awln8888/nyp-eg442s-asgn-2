# Asignment 2
## Description
The objective of this assignment is to:
1. Develop or obtain a working web application.
2. Create a Dockerfile to containerise your application.
3. Build and manage Docker images.
4. Run and manage Docker containers.
5. Use Docker Compose to orchestrate multiple containers where applicable.
6. Publish Docker images to Docker Hub and/or Amazon ECR.
7. Deploy a containerised web application on AWS.
8. Demonstrate that your deployed application is accessible and functioning correctly.
